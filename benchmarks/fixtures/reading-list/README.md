# Reading List

A compact dependency-free Node ESM command-line reading list used only by the Plus Ultra workflow
benchmark.

```text
node src/cli.mjs add "The Left Hand of Darkness"
node src/cli.mjs list
node src/cli.mjs read 1
```

Set `READING_LIST_FILE` to select the local JSON data file. The benchmark initializes each copy as
a new Git repository with fixed author and committer metadata.
